#Static Maps (returns an image)
curl -o test.png "https://maps.googleapis.com/maps/api/staticmap?center=Seattle&zoom=12&size=400x400&key=YOUR_API_KEY_HERE"

# Places API  
curl "https://maps.googleapis.com/maps/api/place/findplacefromtext/json?input=hospital&inputtype=textquery&key=YOUR_API_KEY_HERE"

# Directions API
curl "https://maps.googleapis.com/maps/api/directions/json?origin=Seattle&destination=Portland&key=YOUR_API_KEY_HERE"

# Specific Address
curl -s "https://maps.googleapis.com/maps/api/geocode/json?address=123+Main+Ave,+Bailey,+CO&key=YOUR_API_KEY_HERE"

If any of these work the endpoint is misconfigured as it should only work from specific origins.
